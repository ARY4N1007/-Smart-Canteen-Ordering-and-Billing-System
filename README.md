# Smart-Canteen-ordering-and-Billing-system-
A python based canteen ordering and billing system for ordering menu items, managing items and generating bill of the order.

## About this project :-

This project is a simple canteen ordering and billing system developed using python. It allows user to view the menu, select the food item, manage the quantity of the food item and generate a final bill for their order

## Features :- 

- Displays a categorized menu
- Allows users to select items using item numbers
- Accepts quantity for each selected item
- Supports multiple items in a single order
- Calculates the total bill automatically
- Calculates GST
- Generates a formatted final bill

## Technologies used :- 

- Python
- Dictionary
- Loops
- Conditional Statements
- User Input
- Basic Arithematic
